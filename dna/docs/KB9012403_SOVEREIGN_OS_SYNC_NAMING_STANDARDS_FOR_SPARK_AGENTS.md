# 🌲 Sovereign OS: Sync & Naming Standards for Spark Agents

This guide defines the naming conventions and workspace rules that **Spark** must follow when creating or modifying documents (SOWs, Requirements, Design Specs, and KB entries) in the Google Drive sync repository.

---

## 🎯 1. Core Mandate
All **Statements of Work (SOW)**, **Requirements Specs**, **Design Documents**, and **Knowledge base (KB) articles** generated by Spark must be automatically pulled down to the local Clio workstation. 
To bypass strict rclone sync filters and trigger immediate local ingestion, Spark **MUST** name files using designated tags and prefixes.

---

## 📋 2. Mandatory Naming Rules

Google Drive documents are ingested based on regex-pattern matches. Spark must use one of the following prefixes in the file title:

| Document Type | Mandatory Title Pattern / Prefix | Examples |
| :--- | :--- | :--- |
| **SOW / Requirements / Design Specs** | Prepended with `Work Order: ` or `WO-[ID] — ` | <ul><li>`Work Order: FanStack Media Studio Console Specs`</li><li>`WO-2026-3018 — FanStack Media Studio Console`</li></ul> |
| **Knowledge Base (KB) / Guides** | Prepended with `KB: ` or `Knowledge: ` | <ul><li>`KB: Unified MAM Catalog & Alpha Channel Logic`</li><li>`Knowledge: Govee Care Alert Setup Guide`</li></ul> |

> [!WARNING]
> **Any SOW, requirements, or design doc lacking these exact prefixes will be ignored by the sync loop and will fail to propagate to Clio.**

---

## 📂 3. Google Drive Placement

Documents must be created in either:
1. The Google Drive root directory (`My Drive/`)
2. The designated work orders folder: `SovereignOS_Clio_Sync/work_orders/`

---

## ⚙️ 4. Ingestion Lifecycle (Under the Hood)
For Spark's awareness, once a document is correctly named and placed:
1. The sync loop (`sovereign_pull_sync.sh`) pulls the document, exports it to plain text, and saves it in `/home/james/sovereign_inbox/`.
2. The local Sorting Hat (`organize_inbox.py`) automatically parses the document, creates a corresponding ticket in `sovereign_now.db` (if required), and registers the content in the DNA vault.
3. The sync script moves the original Google Drive file into `SovereignOS_Clio_Sync/work_orders/archive/` to prevent duplicate pulling loops.
