## What Was Cosplay
1. **TTS Voice Synthesis**: The vocalization relies on the browser's built-in Web Speech API (`window.speechSynthesis`), utilizing whichever synthetic voices are available locally on the client browser. There are no actual pre-recorded audio `.mp3` files mapped for the individual advocate persona databases.
2. **Game Event Telemetry Animations**: The event animations (Home Run, Strikeout, Error, Hit, Walk) are triggered by basic case-insensitive substring matches against `gameState.status_msg`. A real semantic parser for ballpark events does not exist; instead, simple string scanning controls the active state.
