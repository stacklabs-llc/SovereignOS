## WHY THIS WO EXISTS (Grounded Findings — confirmed, do not re-derive)

1. **Coupling is runtime, not imports.** Across the core daemons there are effectively no internal import edges; coupling runs through **subprocess** (`sovereign_core_api.py` ≈38 calls, `stream_sniper_daemon.py` 19), the **shared DB**, and **HTTP/WS ports** (11434 Ollama, 8008 WS hub, 5056, 8009, 3008). **Consequence:** a minimal folder will usually boot clean and run half-dead. "Boots without crashing" is therefore NOT success. Per-subsystem smoke tests are the only valid success criterion (KI-029).
2. **The relay is the persona-broadcast engine, mislabeled.** `the_skew_relay.py` serves BOTH The Skew panel (multi-persona) AND the Hot Takes single-persona terminal the Pilot uses daily — it registers `hot_takes_service` (`POST /api/hot_take`, `/dub`, `/voices`, `GET /api/hot_takes`) and handles the `hot_take_rant` WS type. `fanstack_relay.py` has **none** of that wiring — it is an older fork.
3. **Relics are regenerated by live daemons.** `the_skew_relay.py` still emits the dead "FanCast" brand (lines ~164/211/274/1271) — a fossil from the original static-HTML FanStack chat room that Scruffy's Tavern replaced. A clean tree re-litters unless the source is fixed natively (see Phase 5).
4. **Canonical paths are currently "whatever was last typed into a string literal."** Five daemons hardcode `media_vault/…` while `dna/media/` and `dna/media_OLD_BACKUP/` also exist. This WO forces the decision and enforces it.
