## What Broke During Session (And Whether It Was Fixed)
1. **Chat History Scrambling on Reconnect**:
   - *Symptom*: When the socket reconnected, the reloaded history was appended to the bottom of the feed.
   - *Cause*: The queue mechanism assumed any update where `messages.length > displayedMessages.length` was an append. Since the reloaded history contained older messages, the queue processor mistakenly treated the older messages as new.
   - *Resolution*: Implemented `lastDisplayed` lookback index search check. If the last message ID isn't found or isn't a direct append, the component resets the state instead of queueing.
2. **E2E Playwright Selector Timeout**:
   - *Symptom*: Playwright hit a timeout looking for chat messages.
   - *Cause*: The test was hit without the game room query parameter, loading an empty lobby rather than the active Mets-Braves live room.
   - *Resolution*: Targeted `?_game_room=824900` explicitly in the test script.
