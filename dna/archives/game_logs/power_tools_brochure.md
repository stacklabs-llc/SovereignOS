## 🔍 Detailed Plugin Deep-Dive

### Column 1: Live Chat & Real-Time Engagement

> [!NOTE]
> Designed for high-frequency interactive operations, allowing advocates to debate, stream, and interact live.

#### 1. Scruffy's Tavern (`scruffys`)
- **Purpose**: Host real-time gameday chat lobbies and coordinate advocate conversations.
- **Capabilities**: WebSocket-relayed instant message feeds, custom gameday PK mappings, and automated persona commentary.

#### 2. The Skew (Live) (`the_skew`)
- **Purpose**: Live sports debate show staging ground.
- **Capabilities**: Audio feed routing, interactive prompts, and hot topic queues.

#### 3. Hot Takes (`hot_takes`)
- **Purpose**: Track and broadcast highly opinionated advocate rants.
- **Capabilities**: Audio snippet recording, high-intensity transcript rendering, and community rating.

#### 4. Live Chat Sniper (`live_chat_sniper`)
- **Purpose**: Rapid link extraction and targeted interaction triggers.
- **Capabilities**: Scrapes live stream comments to highlight links and capture user inquiries.

#### 5. The Cosmic Sieve (`cosmic_sieve`)
- **Purpose**: Filtering mechanism for high-volume incoming fan promotions and mailbags.
- **Capabilities**: Priority triage queue and spam-filtering engine.

#### 6. Game Log Export (`game_log_export`)
- **Purpose**: Dynamic exporter for active game rooms.
- **Capabilities**: Combines gameday chat logs with play-by-play Statcast logs to compile markdown/JSON reports.

---

### Column 2: Video & Media Processing Suite

> [!TIP]
> The media engine core allows operators to crop clips, sequence storyboards, and synthesize AI-generated footage.

#### 7. Sovereign HoloDex (`holodex`)
- **Purpose**: Cinematic video generation and stitching.
- **Capabilities**: Interacts with local media storage pipelines to compile frame sequences and render high-fidelity animations.

#### 8. Storyboard Deck (`storyboard_deck`)
- **Purpose**: Collaborative video sequencer.
- **Capabilities**: Plan visual flow, drag-and-drop scene cards, and schedule rendering pipeline jobs.

#### 9. Sovereign Watch Party (`sovereign_watch_party`)
- **Purpose**: Historic moment streaming and synchronization.
- **Capabilities**: Real-time synchronized playback controls for multiplayer watch parties.

#### 10. Highlight Heist (`highlight_heist`)
- **Purpose**: Clip ingestion and extraction utility.
- **Capabilities**: Command line wrappers to grab specific play segments by timestamp or play PK.

#### 11. Stream Sniper (`stream_sniper`)
- **Purpose**: Surveillance and acquisition of live video feeds.
- **Capabilities**: Live stream ingestion monitoring and automatic recording trigger.

#### 12. Pile DVR (`pile_dvr`)
- **Purpose**: Local optical capture registry.
- **Capabilities**: Manages USB/webcam video feeds, archiving continuous raw footage.

---

### Column 3: Management, Data, & Cost Control

> [!IMPORTANT]
> The analytical layer provides system health checks, team management, and LLM token usage control.

#### 13. Persona Command Center (`persona_center`)
- **Purpose**: Registry-driven team manager.
- **Capabilities**: Configure prompts, assign models, manage credentials, and deploy advocates.

#### 14. Savant Oracle Analytics (`savant_query`)
- **Purpose**: Structured database MLB analysis.
- **Capabilities**: Directly queries baseball registries and player metrics with visual query builders.

#### 15. Daily Roll Call (`daily_roll_call`)
- **Purpose**: Daily routine bootstrap files and JSON schema verification.
- **Capabilities**: Imports static morning lists, runs dependency roll call, and updates team active state.

#### 16. Media Vault Matrix (`media_vault_matrix`)
- **Purpose**: Central asset and file directory.
- **Capabilities**: Houses generated visuals, PDFs, reports, and player avatars with strict tagging.

#### 17. Token Ledger (`token_ledger`)
- **Purpose**: API consumption tracker and ROI calculator.
- **Capabilities**: Detailed breakdowns of prompt token costs, model performance, and daily budget bounds.
