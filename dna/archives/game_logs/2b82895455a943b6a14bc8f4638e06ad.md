# Walkthrough - DFCT0000478

## Problem Statement
The "Sign Out" / logout button on the Sovereign OS Portal failed to clear active user sessions. Clicking it temporarily reloaded the screen, but the user remained logged in. This prevented the Pilot from logging out to test separate user presence profiles (like switching to Pawel/Patron) for HoloLink UAT testing.

## Root Cause Analysis
1. When a user logs in, the application stores the session JWT token in **both** `localStorage` (as `sovereign_session_token`) and a cookie (`sovereign_session_token`).
2. The `handleLogout` function inside `GlobalSystemBar.tsx` only deleted the key from `localStorage`, then forced a page reload via `window.location.reload()`.
3. Upon reload, `AuthGate.tsx`'s initialization lifecycle ran. It checked if `sovereign_session_token` was present in `localStorage`. If missing, it queried the cookie for `sovereign_session_token`.
4. Because the cookie was never deleted by `handleLogout`, `AuthGate` found the token in the cookie, restored it to `localStorage`, and successfully authenticated the session again, effectively locking the user into a persistent login state.

## Mitigations & Changes

### 1. Front-End Header Dropdown Fix
Modified `handleLogout` in `GlobalSystemBar.tsx` across all micro-frontends:
*   `[GlobalSystemBar.tsx](file:///home/james/SovereignOS/01_Sovereign_Portal/src/components/GlobalSystemBar.tsx)`
*   `[GlobalSystemBar.tsx](file:///home/james/SovereignOS/15_FanStack/src/components/GlobalSystemBar.tsx)`
*   `[GlobalSystemBar.tsx](file:///home/james/SovereignOS/20_AetherVet/src/components/GlobalSystemBar.tsx)`

The updated `handleLogout` calls the auth context's `logout()` function (which clears the cookie cleanly), falls back to clearing the session cookie directly, clears `localStorage`, and reloads the screen:

```typescript
  const handleLogout = () => {
    if (auth?.logout) {
      auth.logout();
    } else {
      localStorage.removeItem(TOKEN_KEY_EXPORT);
      document.cookie = `${TOKEN_KEY_EXPORT}=; path=/; expires=Thu, 01 Jan 1970 00:00:00 GMT; SameSite=Lax`;
    }
    window.location.reload();
  };
```

### 2. Back-End Core API Route Added
Added a standard stateless POST route for logout in `sovereign_core_api.py` to allow the system to conform to server-side logout specifications:
*   `[sovereign_core_api.py](file:///home/james/SovereignOS/scripts/sovereign_core_api.py)`

```python
@fastapi_app.post("/api/auth/logout")
async def auth_logout():
    return {"status": "logged_out"}
```
