# Walkthrough: STRY1779973307 - Persona Center Overhaul, Standard Roster Rebuild, Brand Entropy & Portal Launchpad Integration

## 1. Goal & Context
The objective of this ticket is to overhaul the standard roster presentation in both the Sovereign Portal and Decoupled frontend UIs (FanStack) to implement a highly premium glassmorphic trading card aesthetic. For profiles lacking custom media assets, the UI dynamically renders team-specific stadium backdrop gradients (based on HSL matched MLB primary/secondary colors).

To ensure asset integrity:
- Custom avatar paths for the primary "A-Listers" (`barf`, `bartman`, `peskys_pole_pete`, `steel_city_sufferer`, and `welfare_bucco`) must be strictly protected.
- Standard roster players' database paths must be cleared to allow the frontend to seamlessly render the team-specific fallback stadium cards.
- Integrate the **Persona Center** as a first-class application card visible in both the App Directory and the main Sovereign OS dashboard.
- Resolve proxy routing anomalies on port 3016 (`21_Wildseed_GardenStack`) that caused `/api/personas` calls to return index HTML files.

## 2. Changes Made

### 2.1 Schema & API Support
- **Database Column Added:** Added the `u_visual_style` column to the `persona` and `cmdb_ci_ai_persona` tables in `/home/james/SovereignOS/dna/sovereign_now.db`.
- **Relay and Core API Sync:** Updated `/home/james/SovereignOS/scripts/the_skew_relay.py` and `/home/james/SovereignOS/scripts/sovereign_core_api.py` table routes:
  - `GET /api/now/table/cmdb_ci_ai_persona` now selects and serves `u_visual_style`.
  - `GET /api/now/table/cmdb_ci_ai_persona/{sys_id}` now selects and serves `u_visual_style`.
  - `PUT /api/now/table/cmdb_ci_ai_persona/{sys_id}` maps and updates `u_visual_style` in the `persona` table to persist edits.
  - `POST /api/now/table/cmdb_ci_ai_persona` defaults and inserts `u_visual_style`.

### 2.2 Frontend Card Overhaul & Launchpad Placement
- **Glassmorphic Upgrades:** Revamped `15_FanStack/src/components/PersonaCenter.tsx` and `01_Sovereign_Portal/src/components/PersonaCenter.tsx` to feature modern glassmorphic trading cards.
- **Dynamic Backdrop fallback:** Standardized custom asset checking (`!hasCustomAsset`) to render dynamic team-colored radial gradients and stadium tags:
  ```typescript
  const teamCode = (r.assigned_to || r.department || "").toUpperCase();
  const colors = TEAM_COLORS[teamCode] || { primary: "#0a1118", secondary: "#1a2a38" };
  const fallbackGradient = `linear-gradient(135deg, ${colors.primary}, ${colors.secondary})`;
  ```

- **Sovereign Portal Card:** Added `persona_center` directly as a core entry in `PORTAL_APPS` inside `01_Sovereign_Portal/src/config/PortalApps.tsx` with a rich emerald green theme (`#059669`) and the `Users` icon.
- **DEV Whitelist Expansion:** Added `persona_center` to the DEV mode allowed app list in `SovereignOsPortal.tsx` to enable seamless dev/staging access.

### 2.3 Wildseed GardenStack Proxy Fix (Port 3016)
- **Vite Proxy Addition:** Modified `/home/james/SovereignOS/21_Wildseed_GardenStack/vite.config.ts` to include the `/api/personas` prefix mapping pointing to the core backend API `http://localhost:8090`. This completely solves the issue where Vite fell back to serving `index.html` and triggered JSON parsing errors.
- **Service Recycler:** Gracefully restarted the GardenStack dev server on Port 3016 to activate the new configuration.

### 2.4 Refactored `cmdb_avatar_sync.py`
