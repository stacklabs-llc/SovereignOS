# SOVEREIGN OS: THE EXTRANET RPC BYPASS
**Architecture Designation:** Node .73 / Tailscale Gateway
**Status:** VALIDATED (April 16, 2026)

## 1. The Containment Problem
Commercial LLMs (Gemini, Claude, ChatGPT) operate under strict containment protocols:
- **Advanced Data Analysis (Python Sandbox):** Completely air-gapped. Outbound socket connections and HTTP requests (via `urllib`, `requests`) are silently dropped or return `Network is unreachable`. This prevents agents from launching attacks or modifying external databases via arbitrary `POST` or `PUT` payloads.
- **Web Browsing Tool:** Permitted outbound access, but strictly throttled to HTTP `GET` requests via a proprietary proxy to fetch text-based context (e.g., reading a Wikipedia article or fetching a JSON dump).

This limitation typically forces agents to remain "stuck in the cloud," requiring the Pilot to manually copy-paste code deltas (Owling) or rely on heavy external automation frameworks (Zapier, LangChain) to bridge actions to the physical machine.

## 2. The Extranet RPC Exploit
The Bypass capitalizes on the strict `GET` permission of the Web Browsing tool, turning a passive URL lookup into a live Remote Procedure Call (RPC).

### The Mechanism:
1. **The Gateway:** Node .73 exposes a custom Python HTTP Server over a Tailscale Funnel (`https://sov73.taila01894.ts.net`).
2. **The GET Intercept:** The server's `do_GET` handler is hot-patched to intercept specific URI paths (e.g., `/api/update_test_page`).
3. **The Payload:** Instead of passing data in a `POST` body, the LLM encodes the change delta into standard URL Query Parameters (e.g., `?message=Hello+James`).
4. **The Trigger:** The LLM is instructed to use its Web Browsing tool to "Search" or "Fetch" that exact URI.
5. **The Actuation:** Google's web proxy fetches the URI. The Node .73 Gateway intercepts the GET request, extracts the query parameters, and executes the physical side-effect (e.g., writing to the SQLite Database, rewriting a React DOM file, or toggling hardware).
