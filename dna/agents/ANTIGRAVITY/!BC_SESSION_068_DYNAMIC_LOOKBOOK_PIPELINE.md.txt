## ⚙️ The Golden Goose: Dynamic Lookbook Ingress & Render Pipeline
This architecture enables near-real-time automated generation of comedic storyboard highlights and video slideshows from live game room chatter.

```mermaid
graph TD
    A[Game Room Chat Logs] -->|Sync to Drive| B[Spark Scheduled Job]
    B -->|Generates WO-*.md Lookbook| C[Google Drive Doc]
    C -->|Autosync| D[docs-watcher.service on Clio]
    D -->|Ingress Script| E[sovereign_now.db Ticketing]
    E -->|Argo Agent Poll| F[Veo Video Generator on Argo]
    F -->|Concat & Compile| G[ffmpeg Slide / Video Compilation]
    G -->|Deploy| H[Sovereign Sports Cross Talk Room]
```

### Architectural Breakdown
1. **Log Syncing**: Live game room chat logs are synced dynamically to Google Drive/local workspace.
2. **Spark Job Triggering**: A scheduled Spark instance runs periodically (e.g., during the 7th-inning stretch or at the end of each half-inning) to analyze the chat logs, extract the most absurd or manic highlights, and format them as a structured markdown Work Order (`WO-{game_id}-{inning}.md`).
3. **Docs Watcher & Local Ingress**:
   * The systemd service `docs-watcher.service` running on Clio pulls the markdown document.
   * Clio's `work_order_poll_daemon.sh` parses the `WO-*.md` file out of the watched dropzone.
   * It creates a corresponding ticket/record in the local `rm_story` / `sovereign_tickets` tables of `sovereign_now.db`.
4. **Asynchronous Argo Render (Veo + FFMPEG)**:
   * Argo (the Tailscale compute sandbox) polls `sovereign_now.db` for new work order tickets.
   * For each scene, Argo calls Google GenAI/Vertex **Veo (`veo-3.1-generate-001`)** using the scene's static image and textual prompt to generate a 6-second high-fidelity video clip in parallel.
   * It concatenates the clips losslessly with `ffmpeg` into a continuous 30-to-45-second highlight reel.
5. **Cross Talk Room Playback**: The compiled slideshow reel is dropped into the media assets folder for the **Sovereign Sports Cross Talk room**, instantly updating the fan's playback interface.
